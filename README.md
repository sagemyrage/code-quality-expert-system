# Code Quality Expert System

Экспертная система для оценки качества исходного кода на Go с использованием аппарата нечёткой логики (fuzzy logic). Пользователь отправляет фрагмент кода через веб-интерфейс, система статически анализирует его, вычисляет набор метрик и на их основе формирует итоговую оценку качества вместе с рекомендациями по улучшению.

## Архитектура проекта

Проект организован по слоям: HTTP-хендлеры → сервисы (бизнес-логика) → репозитории (доступ к данным). Анализ кода и нечёткая логика вынесены в независимые пакеты без внешних зависимостей.

```
cmd/web/                   точка входа, сборка зависимостей и запуск сервера
internal/
  analyzer/                статический анализ Go-кода (AST) → метрики
  fuzzy/                   нечёткая логика: функции принадлежности, веса, оценка, рекомендации
  domain/                  доменные сущности (User, Check, CheckMetrics, ...)
  service/                 бизнес-логика (аутентификация, работа с проверками)
  repository/
    postgres/              доступ к PostgreSQL
    redis/                 хранение сессий
  http/
    handlers/              обработчики запросов
    middleware/            аутентификация
    router.go              маршрутизация
web/templates/             HTML-шаблоны страниц
migrations/                SQL-миграции схемы БД
```

## Как это работает

1. **Анализ кода** – исходный код на Go парсится через пакет `go/ast` стандартной библиотеки (без выполнения кода), после чего вычисляется набор метрик:
   - количество строк, доля и количество строк с комментариями;
   - количество функций, средняя и максимальная длина функции;
   - количество условных конструкций (`if`, `switch`) и циклов (`for`, `range`);
   - максимальная глубина вложенности блоков;
   - количество глобальных переменных;
   - количество «длинных» строк (> 120 символов).

2. **Нечёткая оценка** – каждая метрика прогоняется через трапециевидную функцию принадлежности (`trapezoid(x, a, b, c, d)`), которая переводит «сырое» значение в оценку от 0 до 1: чем ближе значение к «плохой» зоне, тем ниже оценка.

3. **Агрегация** – оценки по всем метрикам суммируются с весовыми коэффициентами (наибольший вес – у глубины вложенности и «тяжёлых» по влиянию на читаемость метрик) и нормируются в итоговый балл от 0 до 100.

4. **Классификация и рекомендации** – итоговый балл переводится в качественный уровень (`Плохо` / `Удовлетворительно` / `Хорошо` / `Отлично` / `Идеально`), а по метрикам, набравшим оценку ниже порога, генерируются текстовые рекомендации (например, «уменьшите глубину вложенности» или «декомпозируйте код»).

## Возможности

- регистрация и аутентификация пользователей (пароли хешируются, сессии хранятся в Redis);
- отправка кода на проверку через веб-форму;
- сохранение истории проверок и метрик в PostgreSQL;
- дашборд с историей проверок пользователя;
- детальная страница проверки: метрики, итоговая оценка, рекомендации.

## Технологии

| Компонент       | Технология                         |
|-----------------|-------------------------------------|
| Backend         | Go (`net/http`, стандартный роутинг на основе `http.ServeMux`) |
| БД              | PostgreSQL (через `pgx/v5`)          |
| Сессии          | Redis (`go-redis/v9`)                |
| Шаблонизация    | `html/template`                      |
| Инфраструктура  | Docker / Docker Compose              |
| Миграции        | SQL-миграции в формате `golang-migrate` |

## Запуск проекта

### Требования

- Go 1.25+
- Docker и Docker Compose
- [golang-migrate](https://github.com/golang-migrate/migrate) для применения миграций

### 1. Настройка окружения

```bash
cp .env.example .env
```

Заполните значения в `.env` (доступ к PostgreSQL и Redis, секрет сессии и т.д.).

### 2. Запуск инфраструктуры

```bash
docker compose up -d
```

Поднимутся контейнеры PostgreSQL и Redis с параметрами из `.env`.

### 3. Применение миграций

```bash
migrate -path migrations -database "postgres://<user>:<password>@localhost:<port>/<db>?sslmode=disable" up
```

### 4. Запуск приложения

```bash
go run ./cmd/web
```

Приложение поднимется на порту, указанном в `APP_PORT` (по умолчанию `8080`).

### 5. Использование

Откройте `http://localhost:8080`, зарегистрируйтесь, вставьте фрагмент Go-кода в форму проверки - система вернёт метрики, итоговую оценку качества и рекомендации.
